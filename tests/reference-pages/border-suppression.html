Border Suppression Probe

Diagnostic for V1 length-tuning (Mode 17). See docs/specs/length_tuned_edge_suppression.md.

50 px divider — should remain visible (short edge, no suppression expected)

100 px divider — transitional

200 px divider — transitional

400 px divider — suppression should be noticeable

800 px divider — full suppression expected (long edge)

This paragraph is the control. Word baselines, ascenders, and inter-letter strokes are short oriented edges that should remain salient in the peripheral saliency map even when V1 length-tuning is enabled. If text readability degrades when this mode toggles, length-tuning is over-firing and the steepness or midpoint parameter needs tuning. If the long horizontal dividers above and the page-tall sidebar to the left remain bright relative to text, length-tuning is under-firing and the strength parameter needs to be increased.
