\begin{abstract}
Gaze-contingent tools used in HCI research (BubbleView, ViewSer, ScreenMasker) simulate peripheral vision with Gaussian blur, uniformly destroying spatial structure that real peripheral vision preserves. We present Scrutinizer, an open-source foveated rendering system that applies biologically-grounded peripheral filtering to live web pages at 60\,fps. A GLSL shader implements a pipeline mapped to the visual pathway (retinal ganglion cells~$\rightarrow$ LGN~$\rightarrow$ V1~$\rightarrow$ V4), using Difference-of-Gaussians band decomposition on the hardware MIP chain to approximate cortical magnification (the decreasing fraction of visual cortex allocated per degree of visual field with increasing eccentricity)~\citep{rovamo1979}. The band structure enables per-channel chromatic attenuation and content-aware saliency gating that uniform blur cannot support; empirical comparison shows the full pipeline preserves salient content 5--10$\times$ better than eccentricity-matched Gaussian blur (Section~\ref{sec:validation}). V4 color processing models differential chromatic decay via castleCSF contrast sensitivity functions~\citep{ashraf2024}. V1 crowding distortion is density-gated. We characterize agreement with published psychophysical data across four domains: chromatic decay~\citep{mullen2002,bowers2025}, spatial frequency attenuation~\citep{rovamo1979}, crowding geometry~\citep{bouma1970,toet1992}, and saliency-driven protection~\citep{itti2001}. Section~\ref{sec:validation} characterizes both agreement and discrete-band approximation error. Open source (MIT), with automated validation suite.
\end{abstract}

\section{Introduction}

Peripheral vision is not blurry; it is \emph{differently encoded}. The retina compresses ${\sim}10^7$ photoreceptor signals into ${\sim}10^6$ optic nerve fibers~\citep{curcio1990}, with ganglion cell receptive fields growing with eccentricity (angular distance from the point of fixation, in degrees of visual angle)~\citep{dacey1993} (preserving low-frequency structure while filtering high-frequency detail). Existing gaze-contingent tools (BubbleView~\citep{kim2017}, ViewSer~\citep{lagun2011}, ScreenMasker~\citep{orlov2016}) apply Gaussian blur as a peripheral proxy, uniformly destroying spatial structure and preventing layout-level judgments that real peripheral vision supports. These tools also operate on static images, not live interactive content (Table~\ref{tab:comparison}).

An earlier Scrutinizer prototype~\citep{edmonds2007} demonstrated mouse-contingent Gaussian blur on live web pages using Adobe AIR (2007), establishing real-time fidelity as the key technical challenge. Modern GPU APIs make biologically-grounded filtering practical at 60\,fps---but the gold standard remains out of reach. \citet{rosenholtz2012}'s texture-synthesis ``mongrels'' are the most perceptually accurate peripheral model. \citet{walton2021} demonstrated real-time ventral metamers via smooth moments of steerable filter responses on GPU compute shaders, showing they outperform blur for foveated rendering---but their approach requires compute shader capabilities (CUDA/DirectX) not available in WebGL2 fragment shaders, Scrutinizer's target runtime. Full Portilla-Simoncelli texture synthesis~\citep{portilla2000} with the complete set of summary statistics remains iterative (${\sim}$seconds per frame). Scrutinizer's DoG bands are a pragmatic middle ground: the band decomposition enables per-channel chromatic decay and saliency-gated protection that a single Gaussian kernel cannot express, at a fraction of the cost of full texture statistics, and a WebGPU compute path would enable Walton-style synthesis within the browser.

Scrutinizer contributes: \textbf{(1)}~a DoG band decomposition exploiting the GPU MIP chain that provides individually addressable frequency bands for per-channel chromatic attenuation and content-aware saliency gating, at near-zero cost (9 \texttt{textureLod} calls); \textbf{(2)}~a DOM structure extractor that harvests web accessibility annotations as top-down priors for the saliency pipeline; \textbf{(3)}~a modular architecture where researchers swap implementations at five branch points without modifying the core shader; and \textbf{(4)}~psychophysical validation against four published datasets (Section~\ref{sec:validation}), characterizing both where the pipeline matches human vision data and where discrete GPU approximations introduce measurable error.

These contributions serve three use cases. \textbf{(a)~Vision research:} the branch-point architecture and parameter-controlled shader make Scrutinizer a platform for perceptual experiments. \textbf{(b)~HCI and usability:} instrumented browsers have logged mouse and navigation events for usability research since Uzilla~\citep{edmonds2003}; Scrutinizer extends this lineage so the same cursor stream that drives interaction logging now also drives a biologically-grounded peripheral model on live content. \textbf{(c)~Design evaluation:} designers see which icons, buttons, and headings survive peripheral vision and which collapse into indistinguishable blobs, testing information hierarchy before deployment.

\textbf{Limitations.} The current gaze input is mouse cursor position---unable to capture saccades, reading fixations, or gaze-cursor dissociation. Eccentricity is computed in pixel units; without per-user viewing distance and display DPI calibration, the mapping to degrees of visual angle is approximate. The foveal radius (default 90\,px) is configurable for research use but requires expert calibration of viewing geometry.

\section{Architecture}

The pipeline is a single-pass fragment shader (${\sim}$1200~LOC, GLSL~ES~3.0) with 47 uniforms organized into biological stages, fed by four JavaScript modules (Table~\ref{tab:architecture}).

The architecture exposes five branch points (gaze input, saliency, crowding model, clutter scoring, and structure extraction) where researchers substitute implementations without modifying the core shader. A declarative mode registry (\texttt{modes.json}) defines 10 pipeline configurations as JSON objects, enabling zero-code A/B comparisons between pipeline variants. One switchable mode adapts FOVI's cortical magnification curve~\citep{blauch2026} ($M(r) = 1/(r+a)$, $a{=}2.78^{\circ}$) to MIP levels via $\mathit{mipLevel}(r) = \log_2(1 + r/a)$. At matched eccentricities, Scrutinizer's effective cutoff falls 3.5--4.6$\times$ lower than this CMF adaptation alone (measured by comparing $E_2$-derived band cutoffs against FOVI's CMF at 5$^{\circ}$, 10$^{\circ}$, and 15$^{\circ}$)---the gap represents crowding, contrast sensitivity loss, and color processing that FOVI delegates to downstream learned representations.

\subsection{DoG Band Decomposition}

Retinal ganglion cells have center-surround receptive fields modeled as DoG filters~\citep{kuffler1953}, with field size growing with eccentricity (M-scaling). We decompose the hardware MIP chain into an \emph{approximate} Laplacian pyramid (a multi-scale image decomposition where each level captures a spatial frequency band)---hardware mipmaps use box/bilinear filtering rather than Gaussian convolution~\citep{burt1983}, so band differences are Difference-of-Boxes rather than true DoG, with some spectral leakage between bands:
\vspace{-2pt}
\begin{equation}
\text{band}_k = \text{textureLod}(\mathit{tex}, \mathit{uv}, k/2) - \text{textureLod}(\mathit{tex}, \mathit{uv}, (k{+}1)/2)
\end{equation}
\vspace{-4pt}

Eight half-octave bands ($\sqrt{2}$ frequency spacing) span 5.66\,cpd (serifs) to 0.5\,cpd (layout blocks), each weighted by a smoothstep rolloff with cutoffs at $c_k = E_2 \times (2^{k/2} - 1)$ for $k = 1 \ldots 8$, approximating cortical magnification~\citep{rovamo1979}. The DC residual (mean luminance component) always passes through---even far-peripheral vision preserves mean luminance. Result: peripheral text shows letter shapes rather than uniform fog. Cost: 9 \texttt{textureLod} calls (half-integer LODs use hardware trilinear interpolation) vs.\ 1.

\subsection{Chromatic Processing}

V4 color processing attenuates RG and YV opponent signals independently in Oklab (a perceptually uniform opponent color space)~\citep{ottosson2020} $a$ and $b$ channels using castleCSF contrast sensitivity functions~\citep{ashraf2024}. The DoG band decomposition provides the size axis: each band's center frequency maps to a spatial frequency, and castleCSF returns a per-channel sensitivity at that frequency and eccentricity. Because red-green (L-M) sensitivity declines 4--5$\times$ faster than blue-yellow (S-(L+M))~\citep{mullen2002}, the Oklab $a$ channel is attenuated more aggressively than $b$---preserving blue-green structure into the periphery while red-green fades first.

A suprathreshold correction (adjusting from bare detection thresholds to the perceived appearance of stimuli well above threshold; power-law exponent 0.5) prevents the threshold-based castleCSF from over-attenuating visible texture~\citep{jiang2022}. The decay constants were calibrated using suprathreshold measurements from~\citet{bowers2025}: $\text{rg\_decay}{=}0.072$, $\text{yv\_decay}{=}0.014$. This yields 6 uniforms total: RG/YV sensitivity at three spatial frequency tiers. A lateral R/B channel offset simulates longitudinal chromatic aberration.

\subsection{Crowding and Density Gating}

Crowding is feature binding failure, not blur~\citep{pelli2008}. We approximate its visual effect via simplex noise domain warping and grid-based feature scrambling; this does not implement the summary statistic model of~\citet{rosenholtz2012} but produces qualitatively similar identity loss.

V1 distortion strength is modulated by local element density via a sigmoid gate on the structure map's density channel:
\vspace{-2pt}
\begin{equation}
\text{crowdingFactor} = \text{mix}(0.3, 1.0, \sigma(s \cdot (d - t)))
\end{equation}
\vspace{-4pt}

\noindent where $\sigma$ is the logistic sigmoid, $d$ is local density, $t{=}0.6$ is the threshold, and $s{=}20$ is the steepness. Dense content (text clusters, UI grids) receives full crowding distortion; isolated elements are spared down to a 0.3$\times$ floor. This closes the gap between Bouma's spacing rule~\citep{bouma1970} and the density-dependent crowding observed by~\citet{pellitillman2008}, though the sigmoid parameters are engineering fits, not derived from psychophysical data.

\subsection{Saliency and Structure Priors}

The LGN gates what reaches cortex~\citep{sherman2002}. \citet{mcalonan2008} showed that spatial attention enhances LGN gain at attended locations. We model this as saliency gating via a Web Worker that fuses three channels into a GPU texture:

\textbf{Bottom-up:} Oklab opponent-channel DoG (color saliency) and face detection via face-api.js~\citep{faceapijs} (TinyFaceDetector, 190\,KB).

\textbf{Top-down:} A DOM structure extractor walks the live page's element tree, rendering bounding boxes of text runs, media elements, and interactive controls (including ARIA roles) into an RGBA mask. This provides what bottom-up saliency cannot: knowledge that a control is interactive.

High-saliency regions receive up to 70\% of rendering bandwidth. The saliency worker computes every 15th frame (${\sim}$250\,ms); the DOM scan defers to idle callbacks (300\,ms debounce). A Feature Congestion pipeline~\citep{rosenholtz2007} scores local clutter from Oklab color variance and Sobel edge density, achieving Spearman $\rho = 0.93$ rank-order agreement with the original MATLAB implementation ($N{=}7$ web pages scored at matched resolution). In congestion-gated mode, local clutter modulates peripheral pooling strength by $1.0$--$2.0\times$.

\section{Validation}\label{sec:validation}

We characterize Scrutinizer's rendering pipeline against published psychophysical data across four domains. The method is screenshot-based: known psychophysical stimuli are rendered through the full pipeline (shader compilation, MIP chain, texture sampling, color space transforms), output pixels are measured, and results are compared against published human vision data. We did not test human observers; this is a comparison of computational outputs against published measurements. All stimuli are open-source HTML pages shipped with the repository.

\textbf{Limitations of screenshot-based validation.} Each condition is a single capture---no repeated measurements, no error bars, no capture-to-capture variability assessment. Spatial blur from the peripheral rendering pipeline compresses the dynamic range available for chromatic measurement in Mode~0. Some Tier~2 tests verify that the shader produces its own hardcoded parameters (implementation verification, not perceptual validation). We note these caveats per-wave below.

We organize tests into three tiers. \textbf{Tier~1} (must pass): properties that hold by construction, such as monotonic decay and correct ordering. \textbf{Tier~2} (should pass): quantitative agreement with published data within stated tolerances. \textbf{Tier~3} (stretch): cross-study correlations where discrete GPU approximations meet continuous psychophysical functions.

\subsection{Chromatic Decay}

\textbf{Published basis.} \citet{mullen2002} measured differential distributions of red-green and blue-yellow cone opponency across the visual field. \citet{hansen2009} measured color naming accuracy across the intermediate periphery. \citet{bowers2025} measured chromatic contrast sensitivity in the periphery.

\textbf{Stimulus.} Colored dot arrays (red, green, blue, yellow targets among gray distractors) at 5 eccentricity rings, rendered through Scrutinizer's full pipeline.

\textbf{Results: Tier~1 7/7, Tier~2 1/3, Tier~3 3/3.} The Oklab decomposition into RG ($a$-axis) and BY ($b$-axis) channels correctly predicts peripheral color loss patterns. The key validation is that green tracks the RG decay curve, not BY---hue-based models would get this wrong. Monotonicity checks required non-strict comparison due to 8-bit RGB quantization creating legitimate plateaus at low chroma values. Tier~2 failures: the Bowers suprathreshold ratio deviates 21\% from predicted (threshold 20\%), and rendered pixel values diverge from model predictions at 2/10 ring$\times$channel comparisons---Mode~0's spatial blur compresses the chromatic dynamic range available for measurement. Tier~3: rank ordering of chromatic decay across 4 eccentricities is preserved (Hansen naming data), though with $N{=}4$ this is equivalent to testing monotonicity.

\subsection{Spatial Frequency Attenuation}

\textbf{Published basis.} \citet{rovamo1979} established how spatial resolution scales inversely with eccentricity via the cortical magnification factor. Their $E_2$ values define the half-sensitivity eccentricity for each spatial frequency.

\textbf{Stimulus.} Sine-wave gratings at 0.25--4\,cpd in concentric annuli, analyzed via DFT matched filter at the stimulus frequency.

\textbf{Results: Tier~1 12/16, Tier~2 5/5, Tier~3 0/1.} The 4 Tier~1 failures are test design limitations: the 30\,px foveal patch contains less than one full cycle of the 0.25\,cpd grating, producing nonsensical foveal-relative retention values. These tests should be excluded or redesigned rather than excused. Cross-condition retention (filtered vs.\ unfiltered at the same eccentricity) eliminates this dependency: 4\,cpd drops from 81\% to 61\% across rings while 0.25\,cpd holds at 94--100\%, confirming frequency-selective attenuation. Note: the 5 Tier~2 M-scaling cutoff tests verify that the shader implements its hardcoded $E_2$ parameters correctly (implementation verification); they do not test perceptual accuracy.

The Tier~3 composite Rovamo correlation yields Spearman $r = 0.600$ with $N{=}5$, which is not statistically significant ($p > 0.2$). The 8-band half-octave DoG produces step functions (100\%~$\rightarrow$~0\% at each cutoff) while Rovamo's data shows smooth decay, so moderate rank-order agreement is the best this architecture can achieve.

\subsection{Crowding Geometry}

\textbf{Published basis.} \citet{bouma1970} established that critical spacing scales linearly with eccentricity at ${\sim}0.5\times$. \citet{toet1992} measured radially-elongated interaction zones with ${\sim}$2:1 aspect ratio. \citet{pellitillman2008} formalized the uncrowded window.

\textbf{Stimulus.} Cyan target letters among flanking characters at 3$^{\circ}$, 6$^{\circ}$, and 10$^{\circ}$ eccentricity, in crowded (flanked) and isolated conditions. Metric: spread ratio = standard deviation of target positions, crowded / isolated.

\textbf{Results: 3/7 initial, 7/7 after parameter adjustment.} Four fixes were required: (1)~polar sector R:T ratio corrected from ${\sim}$1:1 to 2:1 (the spoke count formula cancelled radial elongation); (2)~V1 eccentricity scaling extended beyond the parafoveal boundary; (3)~V1 growth factor calibrated from 0.5$\times$ to 1.5$\times$; (4)~composite Rovamo correlation metric replaced per-band Spearman. Fixes (2--3) were calibrated against the test stimuli, making the post-tuning score partially circular.

MIP pooling diameter grows linearly from 2.5\,px at 2$^{\circ}$ to 14.9\,px at 15$^{\circ}$ (spread 1.71$\times$). At 6$^{\circ}$, V1 displacement reaches ${\sim}$69\,px for dense content; Bouma predicts $0.5 \times 6^{\circ} \times 45$\,ppd $= 135$\,px. The measured ratio is 0.51$\times$---close to Bouma's proportionality constant in the parafoveal range where most screen content lives.

The spread ratio \emph{decreases} from 6$^{\circ}$ to 10$^{\circ}$, contrary to Bouma's prediction of increasing crowding with eccentricity. At 10$^{\circ}$, MIP pooling destroys differentiable structure in both crowded and isolated conditions, compressing the ratio toward 1.0. This bounds the effective crowding range to ${\sim}$4--8$^{\circ}$---the parafoveal range where most screen content lives, but an architectural limit for wider-field applications.

The density gate produces a 3.3:1 ratio between dense (69\,px displacement, factor ${\sim}$1.0) and isolated content (21\,px, factor ${\sim}$0.3).

\textbf{Architectural limit.} The V1 stage is eccentricity-dependent but not spacing-dependent---it does not differentiate flanker distances within the crowding zone. A spacing-dependent Bouma curve would require pooling-region-based crowding~\citep{rosenholtz2012}, where features within an eccentricity-scaled region are mixed.

\subsection{Saliency-Driven Protection}

\textbf{Published basis.} \citet{itti2001} established center-surround saliency computation. \citet{hershler2005} showed that faces capture attention pre-attentively.

\textbf{Stimulus.} Four-region test page: color singleton (red among green), luminance singleton (white among dark), inline face image, and homogeneous control. Protection ratio $= \text{deviation}(\text{mod\_on}, \text{baseline}) / \text{deviation}(\text{mod\_off}, \text{baseline})$; values ${<}1.0$ indicate saliency modulation preserves content.

\textbf{Results: Pop-out 6/7, Protection 5/5.} Face saliency is 4.79$\times$ control. The saliency-to-shader path is validated end-to-end for face detection; bottom-up saliency shows weaker results:

On spatial frequency alone, DoG and Gaussian produce near-identical contrast retention slopes on achromatic gratings (ring~4: both $-0.4675$; ring~5: $-0.3592$ vs.\ $-0.3601$). Both pipelines sample from the same MIP chain, so the band decomposition does not add frequency selectivity beyond what the MIP pyramid already provides. The differentiation is architectural: saliency gating, per-channel chromatic separation, and density-gated crowding are pipeline stages that Gaussian blur lacks entirely.

The pattern across all four waves is consistent: the pipeline matches published data where the mechanism maps cleanly to GPU operations (chromatic channel separation, frequency-dependent attenuation, eccentricity-dependent displacement), and diverges where discrete MIP levels approximate continuous psychophysical functions. Three systematic failure modes:

\textbf{Discrete bands vs.\ continuous CSF.} The 8-band half-octave DoG produces step functions at each MIP-level boundary. Rovamo's smooth decay curves yield only $r = 0.600$ ($N{=}5$, not significant). A continuous Gaussian blur with eccentricity-dependent sigma (as in FOVI) would produce smoother curves; indeed, matched Gaussian blur produces identical spatial-frequency attenuation slopes (Section~\ref{sec:validation}.4). The DoG band structure's value is as the substrate for per-band chromatic processing and content-aware gating---dimensions where the pipeline advantage is 5--10$\times$ (Table~\ref{tab:gaussian_saliency}).

\textbf{Strength vs.\ spacing.} The density-gated crowding model modulates distortion \emph{strength} as a function of eccentricity, not \emph{spacing} as a function of flanker distance. The model cannot differentiate a target with flankers at 0.2$\times$ vs.\ 0.5$\times$ eccentricity spacing. This is an architectural limit of per-pixel fragment shaders, which cannot compute summary statistics over pooling regions.

\textbf{Bottom-up saliency resolution.} The saliency worker operates at 256\,px, which cannot resolve UI elements smaller than ${\sim}$60\,px. Face detection operates at 640\,px and provides the dominant protection signal. The bottom-up channel protects page-level layout features but not individual interactive elements.

\textbf{Parameter adjustment during validation.} Four fixes were applied during the crowding wave: (1)~polar sector R:T ratio corrected from 1:1 to 2:1 (a bug fix); (2)~V1 displacement extended beyond the parafoveal boundary (a bug fix); (3)~V1 growth factor calibrated from 0.5$\times$ to 1.5$\times$ (parameter fitting); (4)~composite Rovamo metric replaced per-band Spearman (metric redesign). Fixes (1--2) are corrections to implementation errors. Fixes (3--4) were calibrated against the test stimuli, making those specific results partially circular. Independent validation on held-out stimuli would strengthen the crowding claims.

\section{Applications}

\textbf{Design audit.} The \texttt{scrutinizer-audit} CLI tool and MCP server provide batch Feature Congestion scoring without launching the Electron renderer, enabling CI integration. Designers see which elements survive peripheral vision before deployment. \citet{queen2006} showed that desktop icons with distinct low-spatial-frequency silhouettes are identified ${\sim}$0.5\,s faster in visual search ($N{=}20$, target-among-distractors task), but this analysis requires spatial-frequency filtering that most designers lack access to.

\textbf{Research platform.} The five branch points and declarative mode registry make Scrutinizer a platform for perceptual experiments. Researchers can compare frequency-selective filtering against Gaussian blur on reading speed, swap in eye tracker SDKs or scanpath replay, or test how saliency models interact with crowding---all without modifying the core shader.

\textbf{Education.} Side-by-side comparison modes let users manipulate parameters and see results on their own content.

\textbf{Cognitive architecture integration.} The saliency branch point accepts any bitmap as attentional input, making Scrutinizer a rendering front-end for cognitive models. SNIF-ACT~\citep{fu2007} predicts web navigation via spreading activation between user goals and link text (``information scent''~\citep{pirolli1999}), coupling ACT-R's declarative memory~\citep{anderson2004} with the visual environment. ACT-R's vision module models foveal/parafoveal encoding asymmetries~\citep{salvucci2001}; Scrutinizer could provide the perceptual ground truth it currently approximates with attention parameters. A scent map ($\cos(\vec{g}, \vec{c}_i)$ between goal vector and DOM text nodes) could feed the saliency texture as a top-down prior~\citep{itti2001}, so the texture reflects goal relevance, not just stimulus contrast.

% ============================================================
\section{Open Problems}

\textbf{Continuous cortical magnification.} The 8 half-octave MIP-level differences approximate a Laplacian pyramid, but step boundaries are visible. The Tier~3 validation (Section~\ref{sec:validation}) yields only $r = 0.600$ ($N{=}5$, not significant) against Rovamo's smooth curves. The Gaussian comparison (Section~\ref{sec:validation}.4) confirms that the MIP chain itself provides equivalent frequency selectivity---DoG and matched Gaussian produce identical contrast retention slopes---so the discrete-band architecture's value lies in enabling per-band chromatic attenuation and content-aware gating, not in spatial frequency selectivity per se. A texture-statistics model~\citep{rosenholtz2012} could be swapped in through the crowding branch point. \citet{walton2021} demonstrated that smooth-moment metamer synthesis runs in real time on GPU compute shaders; porting this approach to WebGPU compute would bridge the gap between Scrutinizer's discrete DoG bands and continuous pooling-region statistics, while full Portilla-Simoncelli synthesis with the complete set of summary statistics remains prohibitively expensive for real-time use.

\textbf{Spacing-dependent crowding.} The V1 stage modulates strength, not spacing. Bouma's rule predicts critical spacing as ${\sim}0.5 \times$ eccentricity~\citep{bouma1970}; our gate responds to density, not inter-element distance. A TTM-based implementation would require computing pooling regions that grow with eccentricity and mixing features within each region~\citep{rosenholtz2012}. The crowding branch point already accepts per-pixel modulation; the missing piece is a pooling-region computation pass that the current single-pass fragment shader cannot express.

\textbf{Tiered upgrade path via WebGPU.} A mongrel texture specification defines three tiers beyond the current DoG bands: Tier~2 adds contrast-preserving statistical pooling within the WebGL2 fragment shader (${\sim}$2\,ms); Tier~2.5 targets Walton-style smooth moment synthesis~\citep{walton2021} via WebGPU compute shaders (${\sim}$2--3\,ms); and Tier~3 targets full pooling-region statistical replacement per the TTM~\citep{rosenholtz2012} via WebGPU compute. The crowding branch point accepts any per-pixel modulation, so each tier can be swapped in without modifying the core shader. WebGPU compute is now shipping in Chrome, Safari, and Firefox (behind flag), making this path practical for the first time in browser-based rendering.

\textbf{Suprathreshold correction across channels.} The power-law exponent (0.5) from~\citet{jiang2022} was measured for luminance contrast. We apply it to chromatic channels without evidence that the same exponent holds. The calibrated decay constants~\citep{bowers2025} partially compensate, but the interaction is untested.

\textbf{Mouse proxy error distribution.} Mouse position is a poor stand-in for gaze during reading and visual search. We lack quantitative data on how the eccentricity error distribution differs across task types.

\textbf{Far-periphery chromatic correction.} \citet{bowers2025} show that red-green sensitivity decline slows beyond ${\sim}$40$^{\circ}$, while castleCSF's exponential continues to predict aggressive attenuation. For the desktop viewing distances Scrutinizer targets ($<$30$^{\circ}$), this is not yet visible, but extending to VR/AR would require a correction term.

% ============================================================
\section{Conclusion}

Scrutinizer is a real-time GPU pipeline that maps four biological stages (retinal ganglion cells, LGN gating, V1 crowding, V4 color) onto live web content via DoG band decomposition and castleCSF contrast sensitivity functions. The DoG band structure enables per-channel chromatic attenuation and saliency-gated protection that eccentricity-matched Gaussian blur cannot express---preserving salient content 5--10$\times$ better (Table~\ref{tab:gaussian_saliency}). Validation against four published datasets (Table~\ref{tab:validation_summary}) confirms quantitative agreement where GPU operations map to continuous psychophysical functions, with characterized error at discrete MIP-level boundaries. The branch-point architecture, declarative mode registry, and open-source stimuli are designed so that other researchers can extend the biological grounding as tighter psychophysical measurements become available.
